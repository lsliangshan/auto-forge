# AutoForge 桌面应用设计规格

日期：2026-07-18  
状态：待用户审阅  
视觉基准：[可视化流程编排台](../../design/autoforge-visual-direction.png)

## 1. 产品目标

AutoForge 是面向自动化开发者与业务运营人员的桌面网页自动化平台。首版需要让用户在一个受控、安全的桌面环境内完成以下核心闭环：

1. 创建或打开自动化流程。
2. 从步骤库拖入节点并配置参数。
3. 启动、暂停、继续、重试或停止试运行。
4. 在内置浏览器中观察网页执行过程。
5. 查看逐步日志、错误原因与运行历史。
6. 将流程封装为可安装的自动化工具。

首屏的首要任务是“编排并试运行一个流程”，不使用仪表盘卡片堆叠来展示无关功能。

## 2. 用户与主要场景

### 自动化开发者

需要以低门槛方式组合浏览器、数据、系统与流程控制步骤，配置选择器和参数，快速定位失败节点，并通过受限 SDK 打包工具。

### 业务运营人员

需要从任务列表选择已验证工具，填写少量运行参数，确认权限后执行任务，并查看结果与历史记录。

首版优先保证开发者的流程编排与试运行体验，同时提供运营人员可用的任务运行入口。

## 3. 信息架构

应用采用稳定的左侧主导航，包含：

- 流程：流程列表与可视化编排器，默认入口。
- 自动化任务：已安装工具、运行配置、运行历史。
- 浏览器：多标签内置浏览器、地址栏、前进后退与刷新。
- 发现：可安装工具列表与工具详情。
- 运行记录：跨流程的运行结果与日志检索。
- 设置：主题、下载目录、工具模板下载、开发者选项与关于。

登录入口放在标题栏账户区域。未登录时仍可使用本地编排与试运行；需要发现、发布或跨设备能力时再引导微信扫码登录。

## 4. 视觉与布局

### 整体框架

- 目标窗口：1440 × 1024，最小窗口 1180 × 760。
- 顶部：约 56px 自定义标题栏，承载面包屑、保存状态、撤销/重做、保存和试运行。
- 左侧：约 80px 主导航；编排页再增加约 250px 步骤库。
- 中央：可缩放、可平移的点阵流程画布。
- 右侧：约 320px 属性面板，随选中节点切换内容。
- 底部：约 32px 状态栏；试运行时可展开日志抽屉。

### 设计语言

- 背景以暖白和浅灰为主，石墨色文字，主操作使用钴蓝色。
- 成功状态使用低饱和翠绿色，警告使用琥珀色，错误使用克制的红色。
- 正文基准 14px，重要标题 18–22px；中文优先使用系统无衬线字体栈。
- 圆角以 8px 为主，阴影仅用于浮层、菜单和拖拽态。
- 使用 Lucide 图标或 Element Plus 内置图标，不使用 emoji、手绘 SVG 或装饰性图形。
- 页面分区优先依靠间距、对齐和分隔线，不为每个区域增加卡片外壳。

## 5. 核心交互

### 流程编排

- 步骤库按浏览器、数据、系统、控制分类，可搜索。
- 用户可将步骤拖入画布，并通过连线定义顺序。
- 节点显示名称、类型、序号和校验状态；选中节点显示蓝色描边与连接锚点。
- 属性面板根据节点类型渲染表单，包含基础信息、必填参数和高级设置。
- 画布支持缩放、适应视图、删除、复制、撤销和重做。
- 保存前进行结构校验；未连接节点或缺失必填配置时给出明确定位。

### 试运行

- “试运行”是页面唯一高优先级操作。
- 点击后先保存草稿并校验权限，再进入运行模式。
- 运行状态为 `idle`、`running`、`paused`、`failed`、`completed`、`cancelled`。
- 运行中节点高亮，完成节点显示成功，失败节点显示错误并自动打开日志抽屉。
- 运行模式提供暂停、继续、停止、重试失败步骤和再次运行。
- 暂停发生在步骤边界；不可中断的当前步骤执行完后才进入暂停状态。

### 内置浏览器

- 浏览器页面支持多标签、地址输入、前进、后退、刷新和历史记录。
- 自动化运行时可在独立浏览器窗口或编排页预览抽屉中观察目标页面。
- 页面使用隔离会话；自动化工具不能直接获得 Electron、Node.js、文件系统或原始 CDP 权限。

### 登录与本地状态

- 首次启动直接进入本地工作区，不出现空白页或强制登录。
- 未登录账户区显示“登录”；点击打开微信扫码登录页。
- 登录成功后保存必要的用户标识、显示信息和会话元数据到 SQLite，不保存明文敏感凭证。
- 网络失败不影响本地流程编辑；需要云端能力时显示可重试提示。

## 6. 技术架构

### 技术栈

- Electron + electron-vite
- Vue 3 + TypeScript + Vue Router + Pinia
- Tailwind CSS + Element Plus
- Vue Flow 负责节点画布
- better-sqlite3 负责本地持久化
- Vitest + Vue Test Utils 负责单元与组件测试
- Playwright 负责 Electron 关键路径端到端测试
- electron-builder 负责 macOS、Windows 与 Linux 打包配置

### 进程边界

```text
Renderer（Vue UI）
  -> 类型化 preload API
  -> IPC allowlist
  -> Main services
       -> SQLite repositories
       -> Workflow runtime
       -> Plugin registry / permission gateway
       -> Browser session manager
       -> Auth service
```

Renderer 不直接访问 Node.js。所有 IPC 通道必须在共享契约中声明，并在 preload 中按白名单暴露。Electron 窗口默认开启 `contextIsolation`、`sandbox` 和 `webSecurity`，关闭 `nodeIntegration`。

### 领域模块

- `workflow`：流程模型、校验、状态机、运行与日志。
- `browser`：窗口、标签、导航历史与受控页面能力。
- `plugins`：Manifest 校验、安装、卸载、版本与权限。
- `tasks`：已安装任务、运行参数和历史。
- `database`：迁移、连接与仓储。
- `auth`：扫码状态、用户资料与会话。
- `settings`：持久化偏好与工具模板导出。

## 7. 数据模型

SQLite 首版包含：

- `schema_migrations`：数据库迁移版本。
- `workflows`：流程元数据和画布 JSON。
- `workflow_runs`：运行状态、开始结束时间与错误摘要。
- `workflow_logs`：按运行和步骤索引的结构化日志。
- `installed_plugins`：Manifest、版本、安装位置和校验摘要。
- `plugin_permissions`：已授予或拒绝的权限。
- `browser_history`：URL、标题与访问时间。
- `app_settings`：键值设置。
- `user_sessions`：本地用户展示信息和会话元数据。

数据库通过顺序迁移创建和升级。启动时先完成迁移，再创建主窗口；迁移失败时进入可恢复的错误页，不加载不完整工作区。

## 8. Automation SDK 与插件安全

第三方工具由 `manifest.json`、编译后的入口脚本、类型声明、README 和可选资源组成。SDK 提供受限的 Playwright-like 能力，例如导航、点击、输入、等待、提取文本、受控存储和受控网络请求。

插件必须声明 URL 匹配范围和能力权限。主进程的权限网关在每次高权限调用前校验；默认拒绝文件系统、任意 IPC、完整 cookie、Node.js 和原始 CDP。首版内置一个可编译、可打包、可安装的示例工具和完整接入文档。

## 9. 错误处理

- 表单错误显示在字段附近，并在节点上同步错误状态。
- IPC 错误统一转换为带 `code`、`message` 和可选 `details` 的安全错误对象。
- 工作流错误保留失败步骤、可读摘要、结构化日志和重试入口。
- 插件安装失败不留下半安装目录；使用临时目录校验后再原子移动。
- 数据库和配置写入使用事务或原子替换。
- Renderer 崩溃、未处理异常和主进程错误写入本地诊断日志，不展示敏感信息。

## 11. 测试与验收

### 自动化验证

- 类型检查覆盖 main、preload、renderer 和 SDK。
- 单元测试覆盖 URL 规范化、Manifest 校验、权限决策、流程状态机和数据库迁移。
- 组件测试覆盖步骤库搜索、节点选择、属性表单校验和运行按钮状态。
- Electron 端到端测试覆盖首次启动建库、创建流程、保存、试运行、暂停/继续、浏览器导航和重启后恢复。
- 生产构建与 electron-builder 配置通过验证。

### 可见验收标准

- 首次启动 3 秒内出现可用工作区或明确的初始化进度，不出现空白窗口。
- 1440 × 1024 与最小窗口尺寸下无裁切、重叠或不可达操作。
- 用户可以在演示数据下完成“创建流程 → 配置节点 → 试运行 → 查看日志”的完整闭环。
- 所有主导航页面可访问，核心按钮有真实状态反馈。
- 主题、窗口尺寸、最近流程和浏览历史在重启后保留。
- Renderer 中不存在 Node.js 直连能力，IPC 和插件权限均由类型化白名单控制。

## 12. 首版边界

首版不实现远程工具市场后端、自动更新服务器、支付、团队协作、云端流程同步、插件签名服务和真实微信后端。发现页与扫码登录使用可替换的本地模拟适配器，但 UI、状态机、数据库契约和服务边界完整，后续可接真实接口而无需重写页面。
