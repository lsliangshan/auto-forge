# OpenRouter 待确认费用提示设计

日期：2026-08-19

## 目标

让用户能够直接理解“有 N 笔费用待确认”的含义，同时保持消费摘要卡片简洁。

## 交互设计

- 仅当 `openRouterUnknownCostCount > 0` 时，在“有 N 笔费用待确认”后显示圆形问号图标。
- 使用 Element Plus Tooltip。鼠标悬停或键盘聚焦图标时显示说明。
- Tooltip 文案固定为：

  > 这表示部分 OpenRouter 调用暂未取得准确费用。当前显示的消费金额不包含这些费用，无需手动确认，系统会自动尝试查询。

- 问号图标具有可访问名称，键盘用户可以聚焦并读取提示。

## 实现边界

- 展示层：修改 `BillingUsagePanel.vue`，复用项目已安装的 Element Plus Tooltip 和图标。
- 测试层：扩展现有 `workbench.test.ts` 计费摘要测试。
- 不修改费用统计、自动回查、数据库或 IPC 逻辑。
- 不新增通用 Tooltip 封装；当前只有一个明确调用方。

## 验证标准

- 待确认笔数大于零时，警示文案后存在可聚焦的问号图标。
- Tooltip 包含已确认的完整说明文案。
- 待确认笔数为零时，警示文案、图标和 Tooltip 均不显示。
- 对应组件测试与桌面端类型检查通过。

## 风险与处理

- Tooltip 默认传送到页面根节点，测试应按 Element Plus 的实际渲染行为断言提示内容。
- 图标不触发业务操作，因此只承担说明入口职责，不增加点击行为。
