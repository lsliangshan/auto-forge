# OpenRouter 默认模型价格展示设计

## 目标

当设置页当前大模型供应商为 OpenRouter 时，在“默认模型”模块中同时为下拉选项和收起后的已选模型显示输入、输出价格。价格沿用 OpenRouter 模型目录的美元/百万 Tokens 表达，不改变 DeepSeek 的现有展示。

## 已有数据链路

Main 进程通过 OpenRouter `GET /api/v1/models` 获取模型目录。现有解析逻辑已将 `pricing.prompt` 与 `pricing.completion` 从美元/Token 换算为 `ModelInfo.inputCostPerMillion` 与 `ModelInfo.outputCostPerMillion`，再通过现有 IPC 模型列表契约传给 Renderer。

本次不新增网络请求、不修改 IPC 契约，也不在 Renderer 中维护静态价格。设置页只格式化已有模型元数据，因此刷新模型列表后会自然反映 OpenRouter 返回的当前价格。

## 展示规则

- 仅当 `activeProvider === 'openrouter'` 时附加价格。
- 收起状态使用单行标签：`模型名称 · 输入 $0.40/M · 输出 $1.60/M`。
- 展开状态保留模型名称、模型 ID，并增加 `输入 $0.40/M · 输出 $1.60/M`。
- `/M` 表示每百万 Tokens，币种为美元。
- 数字最多显示六位有效数字并去除不必要的尾零；极小的非零价格仍必须显示为非零值。
- 免费价格显示 `$0/M`。
- 某一侧价格缺失时，该侧显示 `—`，不把未知价格解释为免费。
- 仅存在于本地设置、已不在当前模型目录中的已保存模型没有价格元数据，显示 `输入 — · 输出 —`。
- DeepSeek 仍只显示模型名称与模型 ID，不附加价格占位。

## 组件边界与数据流

改动限定在设置页展示层及其组件测试：

1. `SettingsView.vue` 接收 Store 已过滤的 `ModelInfo` 列表。
2. 页面内纯格式化函数根据当前供应商和两个每百万 Tokens 价格字段生成标签及价格文案。
3. `el-option` 的 `label` 使用完整标签，使 Element Plus 在收起状态显示相同价格。
4. 下拉选项插槽使用分层布局显示名称、价格与模型 ID。

Store、Main 进程 Provider、共享 Schema 和设置持久化均保持不变。

## 错误与边界处理

- 不存在、非有限或无效价格不会进入共享 `ModelInfo` 契约；展示层仍将缺失字段视为未知。
- 极小的非零价格必须保留为非零值，格式化不能把它显示成免费。
- 价格文本只用于展示和筛选标签，不参与模型选择值；保存的仍是原始模型 ID。
- 长标签由现有选择器宽度和溢出行为处理，不改变设置页布局结构。

## 测试与验证

组件测试覆盖：

- OpenRouter 有价格模型的下拉选项显示输入、输出价格。
- 已选 OpenRouter 模型在选择器收起状态显示同一价格。
- `$0/M` 与极小非零价格格式正确。
- 单侧或双侧缺失价格显示 `—`。
- 已保存但不在目录中的 OpenRouter 模型显示未知价格。
- DeepSeek 选项不显示价格文案。

实现后运行聚焦组件测试、Desktop 类型检查、相关完整测试，并执行 `git diff --check`。若仓库存在与本改动无关的旧失败，单独报告，不混同为本功能失败。

## 成功标准

- 选择 OpenRouter 后，默认文本、图片、音频、视频模型的展开选项与收起状态均按上述规则展示输入、输出价格。
- 切换到 DeepSeek 后展示保持不变。
- 模型选择与保存行为不变。
- 自动化测试和类型检查验证展示规则及现有行为未回归。
